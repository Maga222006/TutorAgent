Phase 3: Agentic Workflow & Control Flow (LangGraph/LangChain Agents)
Stage
Trigger
Agent(s) Involved
Outcome & Transition
A. Ingestion
User uploads file.
Summarizer
Outcome: Summary_Store is created. UI displays summary.
B. Quiz Generation
User clicks "Generate Quiz."
Examiner
Outcome: Quiz_Data is generated (all at once). UI enables quiz tasks.
C. Quiz Completion
User submits all answers.
(No Agent)
Transition: User answers sent to the Supervisor endpoint.
D. Feedback Loop
User asks a question (e.g., "Why was I wrong on Q3?").
Supervisor
Action: Supervisor retrieves the source_chunk_id and provides targeted explanation and coaching via chat.
E. Reset
User clicks "New Quiz" / "Back to Summary."
Router
Transition: Jumps back to Stage B (New Quiz) or reloads Stage A data (Summary).
